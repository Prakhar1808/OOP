## Why OOP?
+ to overcome procedural approach to Programming in High Level Languages
Fundamental idea: to *combine* data into a single unit both data and functions operate
such unit is called an *Object*

+ Procedural Programming Flaws it overcomes:
reusability and maintainability

+ in this approach we try to simulate real life into our programs
Languages using OOP approach: C++ (ofc), Java, .NET

### Benefits
+ easy to upgrade the scale of the project/program
+ easy to partition work for the same program
+ software complexity is easily managed
+ maintainace cost is lower
+ easier to implement
