### Objects
*instance of class*
it is the piece of code which represent the real life entity

### Classes
*collection of objects*
class is a structure where we can define methods and variables to utilize by objects
eg:
```c++ 
class student{
    Rno;
    Name;
    Marks;
}```

+ "orange" is an object of "fruit" class
+ "zen" is an object of "browser" class

> without class objects don't exist, and without object we can only use static functions of class
